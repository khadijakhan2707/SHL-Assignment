## Local Setup (Step by Step)

### Prerequisites
- Python 3.10+ installed
- Git installed
- Terminal / command prompt

### Step 1 - Download the project files

Download and unzip, or clone from GitHub after Step 7.

### Step 2 - Create a virtual environment

```bash
cd shl-agent
python3 -m venv venv
source venv/bin/activate        # macOS/Linux
# OR on Windows:
venv\Scripts\activate
```

### Step 3 - Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4 - Get a free Google Gemini API key

1. Visit https://aistudio.google.com/app/apikey
2. Sign up (free, no credit card required for free tier)
3. Go to **API Keys** â†’ **Create Key**
4. Copy the key (starts with `AIza`)

> **Free tier note:** Gemini API has a free tier suitable for development and this assignment.

### Step 5 - Set your API key

```bash
# macOS/Linux:
export GEMINI_API_KEY=YOUR_GEMINI_KEY_HERE

# Windows PowerShell:
$env:GEMINI_API_KEY="YOUR_GEMINI_KEY_HERE"

# Windows CMD:
set GEMINI_API_KEY=YOUR_GEMINI_KEY_HERE
```

### Step 6 - Download the SHL catalog

```bash
python fetch_catalog.py
```

This creates `catalog_cache.json` (the full SHL product catalog). You should commit this file so it ships with your deployment (avoids a cold-start fetch).

### Step 7 - Start the server

```bash
uvicorn main:app --reload --port 8000
```

Test it:
```bash
curl http://localhost:8000/health
# â†’ {"status":"ok","catalog_size":...,"model":"gemini-2.5-flash"}
```

### Step 8 - Run the test suite

```bash
python test_agent.py
```

Expected: 35+ tests across 16 categories. All should pass.

### Step 9 - Manual smoke test

```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"Hiring a Java developer, mid-level, 4 years experience"}]}'
```

## API Reference

### GET /health
```json
{"status": "ok", "catalog_size": 377, "model": "gemini-2.5-flash"}
```

### POST /chat

**Request:**
```json
{
  "messages": [
    {"role": "user", "content": "Hiring a Java developer, mid-level"},
    {"role": "assistant", "content": "What is their seniority?"},
    {"role": "user", "content": "4 years experience"}
  ]
}
```

**Response:**
```json
{
  "reply": "Here are 5 assessments for a mid-level Java developer.",
  "recommendations": [
    {
      "name": "Core Java (Advanced Level) (New)",
      "url": "https://www.shl.com/products/product-catalog/view/core-java-advanced-level-new/",
      "test_type": "K"
    }
  ],
  "end_of_conversation": false
}
```

**Rules:**
- `recommendations` is `[]` when clarifying, refusing scope, or comparing without a committed shortlist
- `recommendations` is 1â€“10 items when the agent commits to a shortlist
- `end_of_conversation` is `true` only when the user explicitly confirms they're done
- Max 8 messages per call (user + assistant combined)
- First message must have `role: "user"`

### POST /evaluate

Runs conversation traces and returns Recall@10 and behavior metrics.

**Request:**
```json
{
  "traces": [{
    "conversation_id": "test_1",
    "messages": [
      {"role": "user", "content": "Hiring a Java developer, mid-level"}
    ],
    "expected_names": ["Core Java (Advanced Level) (New)", "SQL (New)"]
  }]
}
```

**Response:**
```json
{
  "mean_recall_at_10": 0.75,
  "schema_compliance_rate": 1.0,
  "url_validity_rate": 1.0,
  "turn_limit_compliance": 1.0,
  "trace_results": [...]
}
```

### GET /catalog/stats
Returns product count by type and job level.

## Cold Start Note

Render's free tier spins down after 15 minutes of inactivity. The first `/health` call after sleep may take 30â€“90 seconds. The evaluator allows 2 minutes for this. After the first call, all subsequent calls respond normally (typically under 5 seconds).

To keep the service warm before evaluation: ping `/health` once, wait for `{"status":"ok"}`, then begin.
